# 💳 Alke Wallet

Aplicación de billetera digital desarrollada como proyecto Frontend. Permite a los usuarios gestionar sus activos financieros de manera segura y conveniente.

## 🚀 Funcionalidades

- Inicio de sesión con validación de credenciales
- Visualización de saldo disponible
- Depósito y retiro de fondos
- Envío de dinero a otros usuarios
- Historial de transacciones
- Agenda de contactos para transferencias
- Interfaz responsive adaptable a distintos dispositivos

## 📂 Estructura de pantallas

- `login.html` — Inicio de sesión
- `menu.html` — Menú principal con resumen financiero
- `deposit.html` — Depósito de fondos
- `sendmoney.html` — Envío de dinero
- `transactions.html` — Últimos movimientos

## ⚙️ Cómo ejecutar

No requiere instalación. Abre directamente `login.html` en tu navegador.
